# Getting help

Watchcat is a volunteer-run, self-hosted project. There is no paid support.

## Where to ask

| You want to... | Go to |
|---|---|
| Ask a question or discuss an idea | [GitHub Discussions](../../discussions) |
| Report a bug | [Bug report issue form](../../issues/new/choose) |
| Report a false positive or missed offence | [Detection feedback issue form](../../issues/new/choose) |
| Request a feature | [Feature request issue form](../../issues/new/choose) |
| Report a security vulnerability | Follow [SECURITY.md](SECURITY.md). **Never** use a public issue. |

## Before you ask

- Read the [README](README.md) and the documentation in [`docs/`](docs/).
- Search existing issues and discussions.
- Remove server keys, tokens, and real players' usernames or IDs from anything you paste.

## What we cannot help with

- **ER:LC API outages, keys or billing**: contact Police Roleplay Community through their official channels.
- **Your community's moderation decisions**: Watchcat proposes; your staff decide.
- **Hosted versions run by third parties**: the project does not host Watchcat, and anyone offering it as a service is responsible for supporting it.
